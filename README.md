# YovansTrans — Shuttle & Travel Web Portal

Website resmi layanan travel rute **Palu — Poso — Tentena**: pencarian jadwal & tarif kursi, galeri armada, ulasan pelanggan dimoderasi admin, serta pemesanan langsung via WhatsApp.

### Fitur Publik & Admin Panel

- **Publik:** Pencarian jadwal rute/tanggal/kursi, daftar harga transparan, katalog armada, berita promo, dan tombol **Pesan via WhatsApp** otomatis.
- **Admin (`/admin/login`):** Statistik pengunjung & klik lead WhatsApp, manajemen jadwal/rute/armada, dan moderasi ulasan pelanggan.

Dokumentasi pengguna lengkap tersedia di [`USER_MANUAL.md`](USER_MANUAL.md).
